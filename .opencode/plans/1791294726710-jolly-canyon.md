# خطة: خريطة مدينة واقعية وحية 100% (ضمن قيود موقع ثابت + جوال)

## ملاحظة صدق أولاً
"100% حقيقية" بمستوى GTA مستحيلة بموقع ثابت (لا سيرفر، three.js من CDN، أجهزة جوال ضعيفة). المستهدف الواقعي: **مدينة stylized-realistic ثابتة + شوارع مسماة + ليل/نهار + تفاعل بالنقر + كل ماركر في موقعه الصحيح** — وهذا سيجعلها تبدو حقيقية فعلياً على شاشة الهاتف.

## المرحلة 1 — استقرار وتقنية (أساس كل شيء)
**الملف:** `js/map3d.js` (سطر 28-38، 86-98)، `js/ui.js` (سطر 2)
1. `disposeMap()`: إلغاء `raf3` + `traverse(dispose)` + `renderer.dispose()` قبل كل بناء — يوقف تسريب GPU.
2. `setPixelRatio(min(devicePixelRatio,1.75))` — ينقذ البطارية على الجوال.
3. إيقاف الحلقة عند إخفاء التبويب (`visibilitychange` + `IntersectionObserver`) وحذف الدوران التلقائي `sin(now*0.0002)`.
4. `switchTab`: بناء مرة واحدة فقط (`window._mapBuilt`) ثم `refreshMarkers/resume` — بدل إعادة البناء الكاملة.
5. Fallback 2D Canvas عند فشل `import("three")` + زر إعادة المحاولة (بدل رسالة نصية فقط).
6. `polyfill` سطر واحد لـ `roundRect` في `makeLabel` (سطر 20) للمتصفحات القديمة.

## المرحلة 2 — مدينة ثابتة + شوارع + مبانٍ متنوعة (جوهر الواقعية)
**ملفات:** `js/state.js` (حقل واحد `S.citySeed`)، ملف جديد `js/cityKit.js`، `js/map3d.js` (سطر 42-62)، `js/data.js` (إضافة `STREETS`)
1. `S.citySeed` + `mulberry32(seed)` — نفس المدينة لكل تحميل، وتكلفة الحفظ رقم واحد فقط (migration للاعبين القدامى).
2. `STREETS`: 5-7 شوارع بأسماء عربية (الملك فيصل، السوق القديم، الكورنيش، الجامعة، الميناء) — أرصفة + خطوط وسط + لافتات مصغرة عند التقاطعات.
3. `buildDistrict(d,rng)` حسب الحي: تجاري=أبراج زجاجية، فقير=بيوت منخفضة كثيفة، صناعية=مصانع+مداخن، حكومي=مبانٍ بيضاء، قديمة=سوق+مسجد (قبة+مئذنة).
4. نوافذ مضيئة `InstancedMesh` واحد (~300 نافذة = draw call واحد) + خامات مشتركة — من ~80 إلى ~15 draw calls.

## المرحلة 3 — الربط الحقيقي + التفاعل (تجعلها حية)
**ملفات:** `js/cityKit.js` (جديد)، `js/map3d.js` (سطر 74-85، 100-114)، `js/ui.js` (سطر 72-80)، `index.html` (سطر 68)، `js/extra.js` (سطر 174-176)
1. مواقع مشتقة بـ `hash(id)` بدون تغيير بنية الحفظ: `resolveCasePos(c)` و `resolveEmergencyPos(e)` — الطوارئ تظهر في حيها الحقيقي بدل الصف الثابت `(-50+i*5,44)`.
2. وكر رابع لليد الخفية `(-38,-8)` + ماركر مطاردة `Cone` أحمر وامض في `S.chase.x,z` (يفي بوعد "تابع الوميض") + استدعاء `refreshMarkers()` عند بدء المطاردة.
3. دوريات تسير على الشوارع (`waypoints` + `lookAt`) بدل الحركة العشوائية الخارقة للمباني.
4. نقر `Raycaster` (تمييز tap عن drag) على حي/معلم/ماركر → نافذة `modal-card` الموجودة + زر "فتح القضية" عبر `focusCase` الحالية.
5. فلترة طبقات (checkboxes في `map-legend`) + أزرار زوم `+/−` ودعم pinch للجوال.

## المرحلة 4 — ليل/نهار (أرخص واقعية بصرية)
**ملفات:** `js/map3d.js` (دالة جديدة `applyDayNight`)، `js/ui.js` (سطر 24 `renderAll`)
1. `S.hour` تتحكم: نهار `bg أزرق + شمس 1.3` / ليل `bg الحالي + شمس 0.15 + مصابيح + نوافذ مضيئة + نجوم Points + قمر Sprite`.
2. أعمدة إنارة `InstancedMesh` واحد على الشوارع + ضوء مركزي واحد فقط (لا عشرات الأضواء).
3. الانتقال عند تغير الساعة فقط (lerp) — لا تكلفة كل فريم.

## التحقق (إلزامي بعد التنفيذ)
1. `playwright`: لقطتان (ليل/نهار) + تحميلان متتاليان (نفس المدينة = seed يعمل) + التأكد: الوكر الرابع موجود، الطوارئ ليست في `(-50,44)`، المطاردة تومض.
2. كونسول نظيف تماماً (خصوصاً `import three` و `roundRect`).
3. `renderer.info.render.calls < 25` و `getPixelRatio() ≤ 1.75` وإيقاف الـ loop عند إخفاء التبويب.
4. اختبار جوال: pinch + أزرار الزوم + لا تعارض مع السكرول.

## المخاطر
- حفظ قديم بلا `citySeed` → migration تلقائي. لا تغيير بنية `CASES/EMERGENCIES`.
- فشل CDN → fallback 2D. لا انتقال لـ npm/vite (يكسر Vercel الثابت).
- كثرة اللافتات على الشاشات الصغيرة → أحجام مصغرة للشوارع + حد 10 قضايا/5 طوارئ الحالي.
